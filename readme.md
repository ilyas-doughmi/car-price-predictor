# Car Price Predictor

Predicting the resale price (`selling_price`) of used cars from a CarDekho
dataset (4340 cars, in INR). A complete Machine Learning pipeline:
exploration, cleaning, feature engineering, model comparison, optimization.

Project structure:

```
src/step1/   data preparation
src/step2/   baseline models
src/step3/   hyperparameter optimization
src/step4/   final evaluation
src/step5/   prediction app
```

More details will come as the project evolves.
